Windows MIDI Services preview API bundled with KeyKit

Package: Windows.Devices.Midi2 0.99.92-preview.11, Microsoft, x64
Files: bin/Windows.Devices.Midi2.dll and bin/Windows.Devices.Midi2.pri
These files must stay together. The full SDK is not required to run KeyKit.

This bundled edition requires Windows 11 25H2 or later and an enabled Windows
MIDI service. It uses a preview API. It does not install the service, drivers,
tools, or optional transports. WinMM remains KeyKit's default MIDI backend.
